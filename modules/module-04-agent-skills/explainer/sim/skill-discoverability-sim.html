Skill Discoverability Simulator

Module 4 · Agent Skills for IaC · type a task, and see which skills' description field actually matches it closely enough to trigger, and which ones sit there, correctly written, completely unused.

This tool matches on shared words and phrases between your task and each skill's real description field, a simplified stand-in for teaching purposes. A real agent's matching is more capable than plain keyword overlap, but the lesson holds regardless of the exact algorithm: a vague description gives it nothing concrete to match against, no matter how the matching actually works under the hood.

Self-contained, no network calls. The skill descriptions here are the real ones from this course's own repo (demos/m1-agent-preview, and the ones written for M04's own lab), plus one deliberately vague description to show what "correctly written, unused" looks like. Part of Module 4: Agent Skills for IaC, Agentic Infrastructure as Code.
