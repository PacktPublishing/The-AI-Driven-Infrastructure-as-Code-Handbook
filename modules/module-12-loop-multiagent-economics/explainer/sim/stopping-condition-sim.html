Honest model. This is a toy with scripted agent turns, not a live agent. The agent's behaviour in each situation follows what the chapter's real runs showed: given a narrow ticket it fixes the file it was asked about and tries to stop. Real /goal runs on 25 October 2026 all ended clean, after 0 to 8 sends back; the evaluator can do well when the agent shows a real scan in the transcript. The point is what each judge reads, not how often it is wrong. Claude Code also overrides a Stop hook after 8 continuations in a row with no tool use between them. Self-contained, no network calls.
