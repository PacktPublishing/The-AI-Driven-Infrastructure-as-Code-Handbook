# M12 Projects: Loop Engineering, Multi-Agent Ops, Economics

3-5 seeds, hints not solutions.

1. **Write a stopping condition for something you already run repeatedly by hand.** A deploy
   check, a cleanup task, a report you regenerate every week. Would you trust the exact rule you
   just wrote to run unattended? If not, what's still missing?

2. **Design your own escalation path.** For the loop you designed in the lab, or a real one from
   your own work, write down exactly who gets paged when the stopping condition is never met,
   and how fast. No wrong answer, just an honest one.

3. **Fact-check a token-savings claim.** Find a tool, any tool, that advertises a specific
   percentage improvement. Look for an independent, paired measurement behind it. If you can't
   find one, that's the finding.

4. **Sketch a two-agent sequential pipeline for a real task.** One agent's output becomes the
   next one's input. What would the handoff need to look like for the second agent to trust the
   first one's work without re-checking everything itself?

5. **Revisit your Lab 1 exercise.** You wrote three lines back in module one about which steps
   you'd hand to a machine unattended. Read them again now. Would you still trust the same split,
   after everything modules two through twelve actually built?
